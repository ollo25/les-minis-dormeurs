# Godot_Blocks — projet de base du hackathon Le Rebours (19–23 octobre 2026)

**Lire d'abord :** [`README_Demo_Prof.md`](README_Demo_Prof.md) (versions imposées, démarrage rapide, Arduino, documents).

**Sur Mac, avant d'ouvrir le projet dans Godot** si vous l'avez téléchargé en zip, reçu par AirDrop, mail ou Discord : [`INSTALLATION_PLUGINS_MACOS.md`](INSTALLATION_PLUGINS_MACOS.md) (3 étapes, 2 minutes). Avec `git clone`, pas besoin.

Godot **4.7.2** · FMOD GDExtension 6.1.0 (FMOD Studio **2.03**, jamais 2.04) · GdSerial 0.3.0.

**Avant d'ouvrir ce projet, teste ta connexion Arduino en 5 minutes** avec le mini-projet [`godot-arduino-test-connexion`](https://github.com/liaroc/godot-arduino-test-connexion) : même script série, mêmes plugins, une seule scène (flèches, Shift, bouton, capteur).

**Un problème ?** [`docs/DEPANNAGE.md`](docs/DEPANNAGE.md) : symptôme → geste (quarantaine Mac, erreurs FMOD, crash à la sauvegarde, Arduino introuvable, git).

Documents : [`docs/`](docs/) — dépannage, notes pour Tom, checklist de test, questions ouvertes, pièges FMOD, protocole Arduino ↔ Godot, et [`docs/REPRISE-AGENT.md`](docs/REPRISE-AGENT.md) pour quiconque (humain ou agent IA) doit intervenir sur ce projet sans contexte.
